# Interior editorial illustrations

Created October 2, 2026 with the built-in image_gen tool. These are fictional visual allegories, not documentary images. The article identifies them individually. No source data or charts were generated as bitmap text.

## Assets and reproduction

The full frames are preserved as WebP files at 640, 1200, and 1774 pixels wide in `public/images/articles/cloward-piven/`. The `EditorialImage.astro` component selects responsive sizes and provides semantic captions, alt text, and lazy loading. The existing banner is unchanged.

`node scripts/cloward-piven/prepare-editorial-images.mjs <directory-of-generated-originals>` prepares the web assets with Sharp; original filenames are recorded in that script. The generated PNG originals remain in the image tool's output directory.
