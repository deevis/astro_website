How this model works

A stylized world of 3–10 regions, each with localities, resources, a currency, and a government. Time advances in quarters. Click a region for a full dossier.

  • Run starts the clock. Extra Monte Carlo runs are computed immediately, then one representative path animates.
  • Map views color regions by wealth, happiness, economic freedom, or inflation. Statistics shows every region’s four metrics as min–max normalized health bars — not averages. Line thickness is trade; red dashes are conflicts.
  • Setup — open a region and use the Setup tab to pin the reserve issuer, government, gold/Bitcoin settlement, trade preference, and resource richness. Save named starts locally or to a file; you can still save the original start after a run finishes.
  • Results — when a run finishes, a time-series view opens. Toggle regions and datapoints (including money and resource nets). Close it anytime and reopen with Results.
  • Fiat reserve grants seigniorage to the issuer. Gold anchors inflation. Bitcoin lowers inflation for adopting regions and drives a stock-to-flow-style price path.
  • Policy, trade, discovery, and conflict events actually move rates, GDP, and relationships — they are not flavor text.

This is a teaching sketch, not a forecast. Export writes the current path, parameters, and Monte Carlo summary as JSON.
